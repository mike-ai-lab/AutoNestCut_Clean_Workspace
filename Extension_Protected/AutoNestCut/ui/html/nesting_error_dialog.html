💡 How to Fix This

📏
Solution 1: Use Larger Sheet Material
Increase the sheet dimensions to accommodate the component
  1. Click "Open Materials Stock" below
  2. Find material: -
  3. Edit dimensions to be larger than -
  4. Save and retry nesting
✂️
Solution 2: Reduce Kerf Width
Decrease the cutting blade width to gain more usable space
  1. Go to Settings tab in main dialog
  2. Find "Kerf Width" setting
  3. Reduce from current value (try 2-3mm)
  4. Retry nesting
🔄
Solution 3: Enable Rotation
Allow components to rotate 90° for better fit
  1. Go to Settings tab in main dialog
  2. Enable "Allow Rotation" option
  3. Component will try both orientations
  4. Retry nesting
🔧
Solution 4: Modify Component in SketchUp
Reduce the component dimensions in your model
  1. Close this dialog
  2. Find component: -
  3. Edit to reduce dimensions
  4. Run AutoNestCut again

💡 Quick Tip: The most common solution is #1 (Use Larger Sheet). Standard sheet sizes: 2440×1220mm, 2800×2070mm, 3050×1220mm
