Overview

AutoNestCut is a professional SketchUp extension designed for woodworkers, furniture makers, fabricators, and architects who need to optimize material usage and generate cutting diagrams for sheet goods. The extension automatically analyzes your 3D model components and creates efficient nesting layouts to minimize waste and reduce costs.

Getting Started

Basic Workflow

  1. Prepare Your Model: Create your furniture or project in SketchUp using components for each part. Ensure sheet good parts have realistic thickness (3-50mm) and sufficient area.
  2. Select Components: Select the components or groups you want to include in your cutting list. You can select individual parts or entire assemblies.
  3. Launch Extension: Go to Extensions > AutoNestCut > Generate Cut List or click the toolbar button to open the configuration window.
  4. Configure Settings: Set your kerf width and rotation preferences in the Config tab.
  5. Generate Report: Click "Generate Cut List" to process the nesting optimization and view results.
  6. Export: Choose your preferred export format (PDF, HTML, CSV, etc.).

First Run Tips

  • Start with a simple project (5-10 components) to familiarize yourself with the workflow
  • Set up your material database before processing large projects
  • Review the Config tab settings to understand available options
  • Check the Parts Preview tab to verify component detection

Configuration

General Settings

  • Kerf Width: The thickness of your saw blade cut (typically 2-4mm). This ensures proper spacing between parts on cutting diagrams.
  • Allow Rotation: Permits the algorithm to rotate parts for better nesting efficiency, unless grain direction is specified.
  • Units: Choose between millimeters (mm) or inches for all measurements.
  • Precision: Set decimal precision for dimensions (0-3 decimal places).
  • Currency: Select your preferred currency for cost calculations (USD, EUR, GBP, etc.).
  • Area Units: Display areas in square meters (m²) or square feet (ft²).

Material Stock Management

Access via Extensions > AutoNestCut > Material Stock

  • Material Name: Descriptive name for the material (e.g., "Plywood_19mm", "Oak_Veneer")
  • Dimensions: Width and height of standard stock sheets in millimeters
  • Thickness: Material thickness - supports multiple thickness variations per material
  • Price: Cost per sheet for accurate project costing
  • Currency: Currency for pricing (USD, EUR, GBP, etc.)
  • Density: Material density for weight calculations (kg/m³)
  • Import/Export: Share material databases via CSV files
  • Highlight: Click any material to highlight all components using it in your model

Smart Material Detection

When materials are detected in your model but not in your database, AutoNestCut offers intelligent options:

  • Match to Existing: Fuzzy matching suggests similar materials from your database
  • Create Standard Sheet: Add as a new standard sheet material with custom dimensions
  • Create Custom Part: Create a material matching the exact part dimensions
  • Automatic Remapping: Materials with thickness suffixes are automatically matched

CNC/Laser Cutting Workflow

  1. Select a component or group in SketchUp
  2. Go to Extensions > AutoNestCut > 🎯 Flatten for CNC (SVG Export)
  3. Choose which face to export (Front, Back, Left, Right, Top, Bottom)
  4. Toggle dimensions and metadata options
  5. Click "Export SVG" - file opens automatically in Downloads folder
  6. Import SVG into your CNC/laser software

Performance & Optimization

Performance Features

Intelligent Component Caching

Caches analyzed components to avoid re-processing. Subsequent runs are up to 90% faster - from ~10 seconds to under 1 second.

Material Lookup Caching

Material database lookups are cached during processing, eliminating repeated expensive operations.

Single-Pass Processing

Optimized algorithms process components in a single iteration, dramatically reducing processing time.

Selective Entity Search

Focuses only on selected entities instead of searching the entire model, improving performance with large projects.

Async Nesting

Nesting calculations run in background threads with progress indicators, keeping the UI responsive.

Smart Validation

Intelligent limits prevent processing extremely large datasets that could cause performance issues.

Performance Tips

  • Select Specific Components: For large models, select only the components you need rather than the entire model
  • Use Component Caching: The cache is automatically cleared when you modify materials or settings
  • Material Database: Keep your material database organized - remove unused auto-generated materials
  • Batch Processing: Process similar components together for better cache utilization

Troubleshooting

Parts Not Detected

  • Not Components: Ensure parts are modeled as components or groups, not loose geometry
  • Thickness Issues: Check that thickness is between 3-50mm (configurable range for sheet goods)
  • Too Small: Verify parts meet minimum area requirements (typically 100cm²)
  • Nested Too Deep: Components nested more than 3 levels deep may not be detected
  • Selection: Make sure you've selected the components before running the extension

Material Issues

  • Missing Materials Dialog: If you see missing materials, use the smart matching suggestions or create new materials
  • Wrong Material Assigned: Check SketchUp material assignments on components - the extension reads these
  • Thickness Mismatch: Ensure material thickness in database matches component thickness (±1mm tolerance)
  • Multiple Thicknesses: Use the Material Stock window to add thickness variations to existing materials
  • Auto-Generated Materials: Clean up old auto-generated materials using the "Purge" function

Poor Nesting Results

  • Low Efficiency: Enable rotation if grain direction allows - this can improve efficiency by 20-30%
  • Wrong Sheet Size: Adjust stock sheet sizes to better match your parts
  • Too Many Small Parts: Consider grouping similar small parts together
  • Kerf Width: Verify kerf width is set correctly - too large reduces efficiency
  • Large Assemblies: Break down large assemblies into individual components for better nesting

Performance Issues

  • Slow First Run: First analysis takes longer - subsequent runs use cache and are 90% faster
  • Large Models: Select specific components rather than entire complex assemblies
  • Memory Usage: Caching systems are automatically cleared between sessions
  • Extension Reload: If experiencing issues after updates, reload via Ruby Console: Sketchup.plugins_enabled = true
  • Clear Cache: Use "Clear Cache" button in Config tab if you suspect stale data

Export Issues

  • PDF Not Opening: Check that you have a PDF reader installed (Adobe Reader, browser, etc.)
  • SVG Export Fails: Ensure you've selected a single component or group before using SVG export
  • Interactive HTML Too Large: For very large projects, HTML files may be 10-20MB due to embedded 3D data
  • QR Labels Not Generating: Ensure Prawn gem is installed - extension will prompt if missing
  • CSV Encoding Issues: Open CSV files with UTF-8 encoding in Excel/Google Sheets

3D Viewer Issues

  • Assembly Not Showing: 3D assembly viewer only appears when you select a single component/group
  • Textures Not Loading: Some SketchUp materials may not export correctly - use solid colors for best results
  • Viewer Performance: Very complex assemblies (1000+ components) may be slow in 3D viewer
  • Controls Not Working: Ensure JavaScript is enabled in your browser for interactive HTML exports
