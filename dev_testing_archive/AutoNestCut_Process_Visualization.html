✅ Component Validation Process

The validation stage ensures all components are compatible with available materials.

Validation Steps:

1. Load Materials Database
existing_materials = MaterialsDatabase.load_database # Returns: { "Material_Name" => { width, height, thickness, price, ... }, ... }
2. Clean Old Auto-Materials
existing_materials.reject! { |name, _| name.start_with?('Auto_user_') } # Removes old auto-materials to prevent dimension mismatches
3. Validate Each Component
parts_by_material.each do |material_name, part_entries| part_entries.each do |part| # Check: width, height, thickness within limits # Check: material exists in database # If not: auto-create material with exact component dimensions end end
4. Save Auto-Created Materials
MaterialsDatabase.save_database(updated_materials) # Persists new materials for future use

Validation Limits:

Limit Type Value Purpose
Hard Limit Width 4500mm Reject unrealistic dimensions
Hard Limit Height 5500mm Reject unrealistic dimensions
Min Dimension 1mm Reject too-small parts
Max Thickness 500mm Ensure sheet material

Auto-Material Creation Formula:

Auto_user_W{width}xH{height}xTH{thickness}_(SketchUpMaterialName) Example: Auto_user_W232xH348xTH8_(BLUE)

🎲 Nesting Optimization Process

The nesting algorithm places parts on sheets to minimize waste.

Nesting Algorithm:

1. Initialize Board
board = Board.new(material, stock_width, stock_height) # free_rectangles = [[0, 0, stock_width, stock_height]]
2. Sort Parts by Area (Largest First)
remaining_parts.sort_by! { |part| -part.area } # Ensures larger parts are placed first
3. Find Best Position
position = board.find_best_position(part, kerf_width) # Special case: exact-fit parts (dimensions match board) # Normal case: find bottom-left free rectangle that fits
4. Place Part & Update Free Rectangles
board.add_part(part, x, y, kerf_width) # Subtracts placed part from free rectangles # Kerf spacing is included in the subtraction
5. Repeat Until All Parts Placed
if no_parts_fit_on_board create_new_board else save_board_and_continue end

Free Rectangles Algorithm:

Initial State:
Board: 250 x 750mm free_rectangles = [[0, 0, 250, 750]]
After Placing Part (100x200 at 0,0 with kerf=3):
placed_rect_with_kerf = [0, 0, 103, 203] # Subtract from [0, 0, 250, 750] # Result: 4 new rectangles # [103, 0, 147, 750] (right side) # [0, 203, 103, 547] (bottom) # [0, 0, 0, 0] (invalid - filtered out)

Exact-Fit Parts Special Case:

✓ When part dimensions match board dimensions exactly:
  • Part: 232 x 348mm
  • Board: 232 x 348mm
  • Kerf: 3mm
  • Result: Part placed at (0, 0) without kerf spacing requirement
  • Reason: Exact-fit parts are designed to fill the entire sheet

⚠️ Edge Cases & Solutions

Edge Case 1: Material Not in Database

Scenario:
Component has material "BLUE" but it's not in the materials database
Solution:
if !existing_materials.key?(material_name) auto_create_oversized_material(material_name, width, height, thickness) # Creates: Auto_user_W{W}xH{H}xTH{TH}_(BLUE) end

Edge Case 2: Component Larger Than Material

Scenario:
Component: 300 x 400mm, Material in DB: 250 x 350mm
Solution:
if width > material_width || height > material_height auto_create_oversized_material(...) # Creates new material sized to component end

Edge Case 3: Thickness Mismatch

Scenario:
Component: 250 x 350 x 18mm, Material in DB: 250 x 350 x 8mm
Solution:
if (thickness - material_thickness).abs > 0.5 auto_create_oversized_material(...) # Creates new material with correct thickness end

Edge Case 4: Exact-Fit Part Placement

Scenario:
Part: 232 x 348mm, Board: 232 x 348mm, Kerf: 3mm
✓ Solution:
if board.empty? && part.width ≈ board.width && part.height ≈ board.height return [0.0, 0.0] # Place without kerf spacing end

Edge Case 5: Part Cannot Fit on Any Board

Scenario:
Part: 300 x 400mm, Board: 250 x 350mm (part too large)
✗ Error Raised:
ERROR: Unable to place component 'Part' (300x400mm) on sheet (250x350mm). Check dimensions and kerf settings.

Edge Case 6: Multiple Materials with Different Thicknesses

Scenario:
Material "GREEN" has components with 18mm and 100mm thickness
✓ Solution:
# Creates separate auto-materials: Auto_user_W250xH750xTH18_(GREEN) Auto_user_W250xH750xTH100_(GREEN) # Each thickness gets its own material
