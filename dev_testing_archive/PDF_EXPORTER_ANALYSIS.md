# PDF Exporter Analysis - AutoNestCut Application

## Executive Summary

After thorough analysis of the AutoNestCut extension codebase, **only ONE PDF exporter is actively used** in the application:

### ✅ **ACTIVELY USED: PrawnPDFExporter**
- **File:** `Extension/AutoNestCut/exporters/prawn_pdf_exporter.rb`
- **Status:** Currently active and integrated into the main application workflow
- **Usage Location:** `Extension/AutoNestCut/ui/dialog_manager.rb` (line with `export_to_pdf` callback)

---

## Detailed Analysis of All PDF-Related Exporters

### 1. **PrawnPDFExporter** ✅ ACTIVE
**File:** `Extension/AutoNestCut/exporters/prawn_pdf_exporter.rb`

**Status:** **ACTIVELY USED**

**Key Details:**
- Class: `AutoNestCut::PrawnPDFExporter`
- Main Method: `self.generate_pdf_from_html(html_content, settings = {})`
- Dependencies: Requires `prawn` and `prawn/table` gems
- Purpose: Generates PDF from HTML content with exact preview window rendering
- Output: Creates PDF file in Documents folder with naming pattern: `AutoNestCut_Report_[ModelName]_[Timestamp].pdf`

**Integration Points:**
```ruby
# In dialog_manager.rb (line ~450)
@dialog.add_action_callback("export_to_pdf") do |action_context, html_content|
  pdf_path = PrawnPDFExporter.generate_pdf_from_html(html_content, @settings)
end
```

**How It Works:**
1. Takes HTML content as input (generated by the report preview)
2. Uses Prawn library to convert HTML to PDF
3. Applies A4 page size with 15mm margins
4. Renders tables, text, and formatting from HTML
5. Saves to user's Documents folder

## Conclusion

### The Application Uses: **PrawnPDFExporter**

**Why:**
1. It's the only exporter actively called in the main `dialog_manager.rb` workflow
2. It's specifically designed for converting HTML reports to PDF
3. It uses the Prawn gem which is reliable and well-maintained
4. It integrates seamlessly with the HTML preview system

**What's Not Used:**
- `PDFGenerator` is dead code (legacy implementation)
- It's still required in `main.rb` but never instantiated or called
- It appears to have been replaced by `PrawnPDFExporter` during development

**Recommendation:**
If you want to clean up the codebase, you can safely remove:
- `Extension/AutoNestCut/exporters/pdf_generator.rb` (unused)
- The require statement in `main.rb` line 38

Keep:
- `PrawnPDFExporter` (actively used)
- `ViewExportHandler` (used for assembly exports)
- `ReportGenerator` (used for data generation)

## Code Evidence

### Active Usage in dialog_manager.rb:
```ruby
require_relative '../exporters/prawn_pdf_exporter' # Line 6

@dialog.add_action_callback("export_to_pdf") do |action_context, html_content|
  begin
    puts "DEBUG: Exporting to PDF using Prawn..."
    pdf_path = PrawnPDFExporter.generate_pdf_from_html(html_content, @settings)
    
    if pdf_path && File.exist?(pdf_path)
      puts "DEBUG: PDF generated successfully at: #{pdf_path}"
      UI.messagebox("PDF report exported successfully!\n\nLocation: #{pdf_path}")
      @dialog.execute_script("hideProgressOverlay();")
    else
      raise "PDF file was not created"
    end
  rescue => e
    puts "ERROR: Failed to generate PDF: #{e.message}"
    @dialog.execute_script("hideProgressOverlay(); showError('Error generating PDF: #{e.message.gsub("'", "\\'")}')")
  end
end
```
