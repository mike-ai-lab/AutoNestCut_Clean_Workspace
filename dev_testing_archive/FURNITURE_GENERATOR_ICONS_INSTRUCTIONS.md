# Furniture Generator Pro - Icon Instructions

## Icon Requirements

The toolbar needs two PNG icon files:
- `furniture_icon_16.png` (16x16 pixels) - Small icon
- `furniture_icon_24.png` (24x24 pixels) - Large icon

## How to Create Icons

### Option 1: Use an existing icon
Copy any 16x16 and 24x24 PNG files you have and rename them to the required names.

### Option 2: Create simple icons
1. Open any image editor (Paint, GIMP, Photoshop, etc.)
2. Create a 16x16 pixel image with a simple furniture symbol (chair, cabinet, etc.)
3. Save as `furniture_icon_16.png`
4. Create a 24x24 pixel version
5. Save as `furniture_icon_24.png`
6. Place both files in the same directory as `furniture_generator.rb`

### Option 3: Use emoji as icon (Quick method)
1. Take a screenshot of the 🪑 emoji
2. Resize to 16x16 and 24x24 pixels
3. Save as the required filenames

## Note
If the icon files don't exist, the toolbar will still work but will use SketchUp's default icon.
The menu item "🪑 Assets Generator Pro" will always appear in the Plugins menu regardless of icons.
